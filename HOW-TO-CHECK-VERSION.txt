HOW TO TELL WHICH BUILD YOU ARE LOOKING AT
==========================================

Every page now carries a build stamp as the very first line of its HTML source.

  1. Open any page of the site in your browser
  2. Right-click -> "View Page Source"  (or Cmd+Option+U on Mac)
  3. Look at line 1

You should see:

  <!-- Rapid Response Restoration - build f983ab75-149b2888 -->

If line 1 does NOT say that, you are looking at an older copy of the site.


IF YOU ARE STILL SEEING THE OLD STYLING
=======================================

The stylesheet is now loaded as:

  /assets/css/style.css?v=f983ab75

That ?v= value is a hash of the stylesheet's contents. It changes automatically
whenever the CSS changes, which forces every browser to fetch the new file
instead of reusing a cached one. This should make stale-CSS problems impossible
from now on.

If you were seeing old styling before this build, that was why: the filename
never changed, so your browser kept reusing the copy it already had.

To clear anything left over:

  Mac Chrome/Edge:  Cmd + Shift + R
  Mac Safari:       Cmd + Option + R
  Windows:          Ctrl + Shift + R

Or open the site in a private/incognito window, which never uses the cache.


IF YOU ARE VIEWING FROM AN UNZIPPED FOLDER
==========================================

Make sure you extracted THIS zip to a fresh folder rather than overwriting an
old one - some unzip tools skip files instead of replacing them.

Then serve it (do not double-click index.html - the site uses root-relative
paths and needs a server):

  cd rapidresponsedfw
  python3 -m http.server 8000

Then open  http://localhost:8000
